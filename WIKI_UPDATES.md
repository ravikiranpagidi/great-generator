````markdown
# MCP Server

Great Generator includes an optional Model Context Protocol (MCP) server that lets MCP-compatible assistants call selected Great Generator tools from a local developer environment.

> This data is synthetic. It was generated by Great Generator. It is not production data, and it is not an anonymized, masked, or de-identified copy of production records.

## What MCP means for Great Generator

The MCP server is a local wrapper over existing Great Generator public APIs. It does not replace the core package and does not introduce a separate generation engine.

It can expose tools for:

- `generate_from_schema`
- `parse_ddl`
- `generate_relational`
- `validate_query_coverage`
- `export_dataset`

## Install

```bash
pip install "great-generator[mcp]"
```

## Start the server

```bash
great-generator-mcp
```

or:

```bash

## Output behavior

The MCP server writes generated datasets to local files and returns:

- output paths
- row counts
- schema summaries
- small previews
- warnings
- manifest paths
- query coverage report paths when generated

It does not return full datasets in chat.

## Safety limits

Default path root:

```text
current working directory
```

Optional override:

```text
GREAT_GENERATOR_MCP_ALLOWED_ROOT
```

Default row limits:

```text
GREAT_GENERATOR_MCP_MAX_ROWS=100000
GREAT_GENERATOR_MCP_HARD_MAX_ROWS=1000000
```

The server rejects writes outside the allowed root and protects existing files unless `overwrite=True`.

## Architecture

```text
MCP client
  -> Great Generator MCP server
  -> safety layer
  -> MCP tool registry
  -> Great Generator public APIs
  -> local output files and manifest
```

## Troubleshooting

### The command is not found

Install the MCP extra in the environment used by the client:

```bash
pip install "great-generator[mcp]"
```

### Output path is rejected

Use a path under the current working directory or set `GREAT_GENERATOR_MCP_ALLOWED_ROOT` to your local workspace.

### File already exists

Use a new output directory or pass `overwrite=True`.

## Limitations

- v1 uses stdio transport only.
- v1 writes local files only.
- v1 does not expose advisor tools.
- v1 does not connect to databases, cloud storage, or production systems.
- v1 returns summaries and previews rather than full datasets.
````

## FAQ.md

Add these entries:

```markdown
## Does Great Generator require MCP?

No. MCP is optional. The core package works without MCP dependencies.

## Should I install `great-generator[mcp]`?

Install it only if you want to use Great Generator from an MCP-compatible AI assistant or developer tool.

## Does the MCP server change how data is generated?

No. The MCP server calls the same public Great Generator APIs. It does not introduce a separate generation engine.

## Does the MCP server send data to production systems?

No. The v1 MCP server writes generated data to local files and returns summaries, previews, paths, warnings, and manifest information.

## Can the MCP server overwrite my files?

Only when `overwrite=True` is explicitly provided.

## Does the MCP server return full datasets in chat?

No. It returns small previews, row counts, schema summaries, file paths, warnings, and manifest paths.
```
